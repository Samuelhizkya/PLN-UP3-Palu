Download Template Gunakan template ini untuk memastikan format data sesuai.
  • Pastikan file Excel sesuai dengan template yang tersedia.
  • Data akan ditambahkan atau diperbarui berdasarkan Unit dan Periode yang dipilih.
  • Nilai pencapaian dan nilai KPI akan diambil sesuai data pada Excel (tidak dihitung ulang).
  • Pastikan data KPI dan Unit sudah tersedia di sistem.

Pemetaan Kolom Data

Cocokkan kolom dari file Excel dengan field di sistem:

Indikator KPI Terpetakan ke kolom "Indikator"
Target Terpetakan ke kolom "Target"
Realisasi Terpetakan ke kolom "Realisasi"
Satuan Terpetakan ke kolom "Satuan"
Pastikan semua kolom terpetakan dengan benar sebelum melanjutkan.
